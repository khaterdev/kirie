# GIF Grep

Search for GIFs by keyword using Giphy.

## Usage
- "Find a GIF of a cat typing"
- "Send a thumbs up GIF"
- "Search for a celebration GIF"

## How it works
Searches the Giphy API for matching GIFs and returns URLs.

## Setup
Set `GIPHY_API_KEY` from https://developers.giphy.com.
