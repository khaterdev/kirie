# Model Usage

Track token consumption, session costs, and usage trends.

## Usage
- "How many tokens have I used today?"
- "Show my usage breakdown by model"
- "What's my estimated cost this month?"

## How it works
Reads session logs and token counts from the Kirie data directory to compute usage statistics and cost estimates.
