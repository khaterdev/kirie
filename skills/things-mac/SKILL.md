# Things (macOS)

Create and manage tasks in Things 3 via AppleScript and URL schemes.

## Usage
- "Add a task to Things: finish the report"
- "Show my today list in Things"
- "Mark the review task as complete"

## How it works
Uses AppleScript and Things URL schemes to create, read, and update tasks.
