# Healthcheck

Report on system health, resource usage, and service status.

## Usage
- "How's the system doing?"
- "Check disk space"
- "Show CPU and memory usage"

## How it works
Runs system commands to gather CPU, memory, disk usage, uptime, and running process information. Works on macOS and Linux.
