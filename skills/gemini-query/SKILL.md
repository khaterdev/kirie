# Gemini Query

Query Google Gemini models for text generation and reasoning.

## Usage
- "Ask Gemini about quantum computing"
- "Get a second opinion from Gemini on this code"
- "Compare Claude's and Gemini's answers"

## How it works
Sends prompts to the Google Gemini API and returns the generated response.

## Setup
Set `GEMINI_API_KEY` from Google AI Studio.
