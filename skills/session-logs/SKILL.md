# Session Logs

Browse, search, and analyze past Kirie conversation sessions.

## Usage
- "Show my recent sessions"
- "Search past conversations for the API discussion"
- "How many sessions did I have this week?"

## How it works
Reads session log files from the Kirie data directory to display conversation history and statistics.
