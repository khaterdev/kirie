# Gemini Image

Generate and edit images using Google Gemini's multimodal capabilities.

## Usage
- "Generate an image of a futuristic city using Gemini"
- "Edit this image to add a sunset sky"

## How it works
Uses the Gemini API's image generation capabilities to create or edit images from text prompts.

## Setup
Set `GEMINI_API_KEY` from Google AI Studio.
