# Signal Actions

Send and receive Signal messages using signal-cli.

## Usage
- "Send a Signal message to +1234567890"
- "Check my Signal messages"

## How it works
Uses `signal-cli` to send and receive end-to-end encrypted messages.

## Setup
Install `signal-cli` and register your phone number.
