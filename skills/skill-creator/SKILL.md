# Skill Creator

Interactively create new Kirie skill definitions with proper SKILL.md format.

## Usage
- "Create a new skill for managing Docker containers"
- "Help me write a skill definition"

## How it works
1. Guides you through defining the skill name, description, and requirements
2. Generates the SKILL.md file with proper YAML frontmatter
3. Saves it to the managed skills directory
