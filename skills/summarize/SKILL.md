# Summarize

Generate concise summaries of articles, documents, web pages, or long text.

## Usage
- "Summarize this article"
- "Give me the key points from this PDF"
- "TL;DR this web page"

## How it works
1. Fetches or reads the provided content
2. Extracts key points and main arguments
3. Produces a structured summary with bullet points
